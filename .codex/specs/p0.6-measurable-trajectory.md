# P0.6: Measurable Trajectory & Telemetry

## Goal
Upgrade the `TrajectoryRecorder` and `AuditState` to capture quantitative metrics for evaluation (TraceForge integration).

## Requirements
1. **Tool Telemetry**:
   - Update `process_semgrep_output` and `process_generic_tool` in `compressor.py` to calculate and return `raw_char_count` and `compressed_char_count`.
2. **Validator Telemetry**:
   - Ensure the `validator_node` explicitly records the ratio of `total_candidates` to `verified_count` (already partially implemented, ensure it writes successfully to the trajectory).
3. **Graph Metadata**:
   - Update `TrajectoryRecorder.finalize` in `trajectory.py` to sum the total `raw_char_count` vs `compressed_char_count` across the entire run and write the `compression_ratio` to `metadata_<run_id>.json`.
4. **Testing**:
   - Add a test in `tests/test_trajectory.py` that mocks a run and verifies the `metadata_*.json` file correctly calculates the total `compression_ratio`.

## Definition of Done
The system outputs a final metadata file that mathematically proves the context-compression thesis (e.g., "Ingested 85,000 chars, retained 4,200 chars, compression ratio: 20.2x").
