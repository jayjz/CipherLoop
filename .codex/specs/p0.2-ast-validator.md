# P0.2: AST-Based Evidence Validation

## Goal
Replace the regex heuristics in `src/cipherloop/executor/validator.py` with Python's `ast` module.

## Requirements
1. The validator must parse the target file into an Abstract Syntax Tree.
2. It must explicitly detect untrusted sources (e.g., `request.args`).
3. It must explicitly detect execution sinks (e.g., `subprocess.run`, `os.system`).
4. Update `VerifiedFinding` mapping to prove the connection.
5. Create a safe fixture (`fixtures/toy/app_safe.py`) and prove the validator rejects it.

## Definition of Done
All tests pass, and `test_validator.py` proves false positives are rejected.
